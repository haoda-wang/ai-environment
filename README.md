> 环境工程 × 计算机 × 深度学习 ｜ 主线：AI + 双碳 ｜ 周期：大学三年，V1 → V7 递进
> 目标：保研（985/211）+ 交叉方向读研

## 为什么是「AI + 双碳」

真实的碳排放数据一年只有一个统计值，没法直接建模；而用电量等**活动数据**有高频数据，且与碳排放强相关：

> **碳排放 = 活动数据 × 排放因子**

所以本系列的主线方法：**先预测活动数据，再换算碳排放**——环境专业知识（碳核算）× 机器学习（时序预测）的结合点。

## 版本路线

| 版本 | 时间 | 能力轴 | 主题 | 状态 |
|---|---|---|---|---|
| V1 | 大二上·寒假 | 预测 | 传统 ML 闭环 | 🚧 进行中 |
| V2 | 大二下·暑假 | 预测 | LSTM 时序建模 | 计划 |
| V3 | 大三上 | 预测 | 注意力进阶 | 计划 |
| V4 | 大三下·暑假 | 感知 | 计算机视觉 | 计划 |
| V5 | 大四上 | 决策 | 强化学习 | 计划 |
| V6 | 大四下 | 知识 | RAG 知识问答 | 计划 |
| V7 | 大四下~研究生 | 编排 | Agent 智能体（收官） | 机会性 |

> **优先级**：V1–V3 必做，V4–V6 加分，V7 机会性。
> **节奏**：学期内保温（每周 2–3 小时），主攻放寒暑假；**绩点优先级高于项目**。
