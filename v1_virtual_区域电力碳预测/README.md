# v1_virtual · 区域电力碳预测（合成数据演示版）

> **版本说明**：本项目为 V1 演示版，使用**合成数据**旨在完整跑通「数据 → 特征 → 模型 → 评估」的机器学习闭环。  
> **真实数据版**请参见后续 `v1_truth` 分支（该版本指标方具备实际参考价值）。

## 技术路线

### 核心思路
**碳排放 = 活动数据（用电量）× 排放因子**  
本版本聚焦于前半段：**用电量预测**。通过构建时序特征，对比多种模型效果，验证周周期性规律。

### 处理流程
```text
数据生成(Step1) → 数据检验(Step2) → 可视化探索(Step3) → 缺失值清洗(Step4) 
→ 滞后/滚动特征工程(Step5) → 时序切分(Step6) → 基线模型(Step7) 
→ 线性回归(Step8) → 随机森林(Step9) → XGBoost(Step10) → 综合评估
```

## 结果（合成数据，指标不作数；单次运行示例，名次随种子波动）

| 模型 | RMSE | MAE | MAPE | 说明 |
|---|---|---|---|---|
| 基线（明天=今天） | 4.711 | 3.896 | 4.02% | 及格线 |
| 线性回归 | 2.525 | 2.148 | 2.24% | 权重显示 lag_7 最重要 |
| 随机森林（默认） | 2.022 | 1.723 | 1.78% | lag_7 重要性 0.74 |
| 随机森林+网格搜索 | 1.856 | 1.632 | 1.69% | 本轮最优，但稳定性不足 |
| XGBoost (lr=0.5) | 2.616 | 2.077 | 2.02% | 学习率过高导致过拟合|

> 噪声 σ=3 对应 MAE 理论下限 ≈ 2.39，17 天小测试集的单次结果可能因运气低于它。

## 三条核心结论

1. **周周期规律得到交叉验证**:两个不同原理的模型（线性回归 & 随机森林）独立认定 `lag_7`（上周同一天）是最重要特征,证实了数据中植入的“周末-8”规律已被有效捕获。
2. **小样本测试结果不稳定**:小测试集（17 天）上的模型名次不稳定：换一次随机种子排名就会翻转，**切勿过度解读单次运行的优劣**。
3. **调参不等于测试集提升**网格搜索在训练集内部交叉验证选参，当数据量较小时，极易出现过拟合，无法保证在测试集上泛化更好。。

## 过程问题

-  可视化:matplotlib 先画日期再画数值 → y 轴被污染成"1970 年"；**画图永远显式给 x 和 y**
-  模块导入副作用:`from step8_linear import y_pred` 会执行整个文件 → 执行代码要套 `if __name__ == '__main__'`
- 指标计算陷阱:`mean_squared_error` 重复导入并别名为 rmse → MSE==RMSE 假象；sklearn 的 MAPE 返回小数需 ×100
- git 误建在上级目录 + 大数据集入库 → push 193MB 必失败；**数据集永远不进 git**
- 复现性保障:模型不固定 `random_state` → 同代码两次结果不同

## 核心结论与未来展望

### 本阶段核心结论

1. **周周期规律得到交叉验证**:两个不同原理的模型（线性回归 & 随机森林）独立认定 `lag_7`（上周同一天）是最重要特征,证实了数据中植入的“周末-8”规律已被有效捕获。
2. **小样本测试结果不稳定**:小测试集（17 天）上的模型名次不稳定：换一次随机种子排名就会翻转，**切勿过度解读单次运行的优劣**。
3. **调参不等于测试集提升**网格搜索在训练集内部交叉验证选参，当数据量较小时，极易出现过拟合，无法保证在测试集上泛化更好。。

### 未来展望

1.  **从合成数据迈向真实场景**：当前所有结论均基于理想化合成数据，下一步需接入沈阳/辽宁真实用电与碳排放数据，验证周周期规律在现实噪声中的鲁棒性，并将评估指标从“流程正确性”转向“业务可用性”。
2.  **构建多尺度预测能力**：当前仅支持单步日预测，未来需扩展至 7 天 / 30 天多 horizon 预测，并探索直接多步输出与递归预测策略的权衡，以支撑不同时间尺度的碳管理决策。
3.  **深化模型可解释性与不确定性量化**：除特征重要性外，引入 SHAP 值分析非线性交互效应；同时增加预测区间估计（如分位数回归、贝叶斯方法），为碳排放预警提供置信度参考，弥补点预测在风险管理中的不足。
4.  **打通碳核算全链路闭环**：将用电量预测结果与官方电网排放因子动态对接，实现“活动数据 → 碳排放”的自动化换算，并建立因子版本追溯机制，确保碳核算结果的可审计性与时效性。
