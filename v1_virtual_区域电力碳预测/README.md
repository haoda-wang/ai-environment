# v1_virtual · 区域电力碳预测（假数据版）

> V1 的demo版：用**合成数据**把「数据 → 特征 → 模型 → 评估」完整闭环走通。
```
> ML流程:   读数据->数据预处理->特征工程->模型训练(->保存模型)->预测评估
```
> 真实数据版见后续 `v1_truth`——那才是指标作数的版本。

| 版本 | 数据 | 目的 | 状态 |
|---|---|---|---|
| **v1_virtual**（本目录） | 合成 90 天用电量 | 练手：走通全流程，掌握每个环节 | 完成 |
| **v1_truth** | 真实公开数据（沈阳/辽宁） | 实战：指标可写进报告 | 🔜 待做 |

## 一句话思路

**碳排放 = 活动数据（用电量）× 排放因子** —— 先预测用电量，再乘电网排放因子换算碳排放。

本版本只做前半段（预测用电量）。

## 方法链条

```
生成数据(step1) → 查看检验数据(step2) → 数据可视化(step3) → 清洗缺失(step4)→ 滞后/滚动特征(step5) → 时序切分(step6) → 基线(step7)→ 线性回归(step8) → 随机森林(step9) → XGBoost(step10) → 对比图收工
```

## 结果（合成数据，指标不作数；单次运行示例，名次随种子波动）

| 模型 | RMSE | MAE | MAPE | 说明 |
|---|---|---|---|---|
| 基线（明天=今天） | 4.711 | 3.896 | 4.02% | 及格线 |
| 线性回归 | 2.525 | 2.148 | 2.24% | 权重显示 lag_7 最重要 |
| 随机森林（默认） | 2.022 | 1.723 | 1.78% | lag_7 重要性 0.74 |
| 随机森林+网格搜索 | 1.856 | 1.632 | 1.69% | 本轮第一；名次不稳定 |
| XGBoost (lr=0.5) | 2.616 | 2.077 | 2.02% | 对比图上可见过拟合 |

> 噪声 σ=3 对应 MAE 理论下限 ≈ 2.39，17 天小测试集的单次结果可能因运气低于它。

## 三条核心结论

1. **两个不同原理的模型（线性回归 & 随机森林）独立认定 `lag_7`（上周同一天）是最重要特征**——交叉验证了数据的主规律是周周期（周末 −8）。
2. **小测试集（17 天）上的模型名次不稳定**：换一次随机种子排名就会翻转，单次结果不可尽信。
3. **网格搜索在训练集内部交叉验证选参，不保证测试集上更好**；数据量小时尤甚。

## 过程问题

- matplotlib 先画日期再画数值 → y 轴被污染成"1970 年"；**画图永远显式给 x 和 y**
- `from step8_linear import y_pred` 会执行整个文件 → 执行代码要套 `if __name__ == '__main__'`
- `mean_squared_error` 重复导入并别名为 rmse → MSE==RMSE 假象；sklearn 的 MAPE 返回小数需 ×100
- git 误建在上级目录 + 大数据集入库 → push 193MB 必失败；**数据集永远不进 git**
- 模型不固定 `random_state` → 同代码两次结果不同
