# V1 · 区域电力碳预测

> 系列第一步：不追花活，用传统机器学习把「数据 → 特征 → 模型 → 评估」闭环走通。

## 一句话思路

**碳排放 = 活动数据（用电量）× 排放因子** —— 先预测用电量，再乘电网排放因子换算成碳排放。

## 设定

- 区域：沈阳 / 辽宁
- 预测目标：工业用电量（真实数据到位前的代理目标）

## 文件说明

| 文件 | 作用 | 状态 |
|---|---|---|
| `make_demo_data.py` | 生成 90 天演示数据（合成数据，仅练手） | ✅ |
| `check_data.py` | 数据体检：类型 / 缺失 / 日期连续性 | ✅ |
